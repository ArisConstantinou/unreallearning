Πραγματικός συνομιλητής AI

Η στατική έκδοση δεν περιλαμβάνει AI server. Προαιρετικά μπορείς να συνδεθείς σε δικό σου συμβατό server· από το δημόσιο HTTPS site χρειάζεται HTTPS endpoint. Το API key παραμένει στον server. Χωρίς σύνδεση λειτουργούν οι ασκήσεις, η διάγνωση και οι τοπικές εξηγήσεις.

Δεν έχει συνδεθεί πάροχος AI.

Η χρήση API χρεώνεται ξεχωριστά. Μην ανεβάσεις κλειδιά ή token σε δημόσια φιλοξενία. Το τοπικό HTTP είναι μόνο για έμπιστο ιδιωτικό Wi-Fi.

Χρήση σε κινητό

Άνοιξε την ενότητα KINÉ από τον σύνδεσμο του Dungeon Mentor στον browser του κινητού. Οι ασκήσεις λειτουργούν χωρίς πρόσθετο server. Τοπικά στο PC, η σταθερή διεύθυνση του έργου είναι http://127.0.0.1:5173/kine/.

Η πρόοδος αποθηκεύεται στον συγκεκριμένο browser και δεν συγχρονίζεται αυτόματα με άλλη συσκευή. Για μεταφορά χρησιμοποίησε την εξαγωγή και εισαγωγή JSON.

Τι προσομοιώνεται

39 τύποι κόμβων, απλοποιημένη κίνηση Character, διαδικαστικές πόζες και προετοιμασμένα assets. Δεν εκτελούνται .uasset, πλήρης φυσική, όλο το Blueprint API, Multiplayer ή πλήρης Animation Editor.
