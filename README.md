# Dungeon Mentor

Στατικό εκπαιδευτικό εργαστήριο για Unreal Blueprint και dungeon modeling. Το δημόσιο URL είναι <https://arisconstantinou.github.io/unreallearning/>.

## Τοπική ανάπτυξη

Από τη ρίζα του repository:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Άνοιξε <http://127.0.0.1:5173/>. Η **5173** είναι η σταθερή θύρα αυτού του project. Αν χρησιμοποιείται ήδη, βρες τη διεργασία και μην ξεκινήσεις δεύτερο server ή αλλάξεις θύρα σιωπηρά. Δεν απαιτούνται `npm install`, bundler ή εξωτερικά assets.

Για τους ελέγχους λογικής:

```powershell
npm test
```

## Δομή

| Αρχείο | Ρόλος |
| --- | --- |
| `index.html` | Στατικό HTML και σειρά φόρτωσης αρχείων |
| `src/styles.css` | Responsive εμφάνιση |
| `src/core.js` | Blueprint κόμβοι, συνδέσεις, προσομοιωτής, διαγνωστικοί κανόνες |
| `src/course.js` | Μαθήματα και έννοιες |
| `src/scene.js` | Canvas 3D σκηνή και εναλλακτική απόδοση |
| `src/app.js` | Διεπαφή, αποθήκευση, αλληλεπιδράσεις, προαιρετική σύνδεση AI |
| `tests/core.test.cjs` | Έλεγχοι βασικής συμπεριφοράς προσομοιωτή |

Τα scripts είναι κλασικά browser scripts και φορτώνονται με αυτή τη σειρά. Ο πυρήνας εξάγει και CommonJS API για τους ελέγχους. Η πρόοδος αποθηκεύεται μόνο στο `localStorage` του browser, με δυνατότητα εξαγωγής/εισαγωγής JSON. Η αλλαγή domain ή διαδρομής δεν μεταφέρει αυτόματα την πρόοδο.

## Όρια της δημόσιας έκδοσης

Το GitHub Pages φιλοξενεί μόνο στατικά αρχεία. Η τοπική καθοδήγηση λειτουργεί χωρίς server. Η προαιρετική ελεύθερη απάντηση AI χρειάζεται **ξεχωριστό προσωπικό server** συμβατό με τα υπάρχοντα endpoints `/api/status` και `/api/ask`, καθώς και προσωπικό API key. Δεν περιλαμβάνεται `server.py`, API key ή δημόσιο backend σε αυτό το repository. Το εργαστήριο προσομοιώνει μέρος της συμπεριφοράς Unreal και δεν εκτελεί `.uasset` ή το πραγματικό project του χρήστη.

## Δημοσίευση

Το GitHub Pages δημοσιεύει τη ρίζα του branch `main`. Η `.nojekyll` αποτρέπει πρόσθετη επεξεργασία των στατικών αρχείων. Για κάθε αλλαγή: `npm test`, έλεγχος desktop και mobile στο τοπικό URL, commit και push στο `main`, έπειτα έλεγχος του δημόσιου URL. Το αρχικό μονολιθικό HTML διατηρείται στο commit `9eaaba4`.
